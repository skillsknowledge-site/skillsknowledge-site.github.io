SK Portfolio redesign notes
===========================

Upload the files in this folder together as one static website. The graphic design
page (graphics.html and graphics.css) is unchanged.

Account sign-up
---------------
Sign-up accepts either an email address or a phone number and asks for a username.
Google sign-in also asks new accounts for a username. The site uses the existing
Supabase settings in config.js. Phone sign-up requires an SMS provider enabled in
Supabase Authentication.

Checkout
--------
Buy Now opens a structured checkout for video and coding services. Orders and
transaction records are saved in the current browser and shown in the account page.
No payment is charged or verified. Connect a payment provider before accepting real
payments.

Appeals
-------
The appeal page sends blocked-account appeals through the existing
submit_appeal(identifier, message) Supabase function. Admins can review and close
appeals in the Admin panel. The SQL setup file is not copied into this website.

Analysis
--------
The admin Analysis tab uses the existing admin_list_users function and last_seen
profile field to show shared recent account activity. The supplied schema does not
store visit counts or session duration, so the panel identifies those values as
unavailable instead of showing browser-only figures. Product ratings are marked
for a future feature.
